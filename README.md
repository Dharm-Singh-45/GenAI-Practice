# 🎓 DSA Learning Assistant

An AI-powered web application to help you learn Data Structures & Algorithms with interactive Q&A, powered by Google's Gemini AI.

## ✨ Features

- 💬 **Interactive Chat Interface** - Ask DSA questions and get detailed explanations
- 📊 **Real-time Statistics** - Track your learning progress with success rates and response times
- 📚 **Question History** - All your questions are saved and searchable
- 🔍 **Search Functionality** - Find past questions quickly
- 📱 **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- 💾 **Persistent Storage** - Your history and stats are saved locally
- 🎨 **Beautiful UI** - Modern gradient design with smooth animations

## 🛠️ Setup Instructions

### Option 1: Use GitHub Pages (Recommended)

1. **Fork this repository**
   - Click the "Fork" button at the top right of this page

2. **Enable GitHub Pages**
   - Go to your forked repository
   - Click on "Settings" → "Pages"
   - Under "Source", select "main" branch
   - Click "Save"
   - Your site will be live at: `https://yourusername.github.io/repository-name`

3. **Configure your API Key**
   - Visit your deployed site
   - Click the ⚙️ Settings button in the top right
   - Enter your Gemini API key
   - Click "Save Settings"

### Option 2: Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/dsa-learning-assistant.git
   cd dsa-learning-assistant
   ```

2. **Open in browser**
   ```bash
   open index.html
   ```
   Or simply double-click `index.html`

3. **Configure your API Key**
   - Click the ⚙️ Settings button
   - Enter your Gemini API key
   - Click "Save Settings"

## 🔑 Getting Your API Key

1. Go to [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy the generated key
5. Paste it in the Settings of the app

**Note:** Keep your API key secure and never share it publicly!

## 📖 Usage

1. **Ask Questions**
   - Type your DSA question in the input box
   - Press Enter or click "Send"
   - Wait for the AI response (3-second rate limit between requests)

2. **View Statistics**
   - See total questions, success rate, and average response time in the header
   - Check detailed stats in the sidebar

3. **Search History**
   - Use the search bar in the sidebar to find past questions
   - Click on any history item to view the full conversation

4. **Clear History**
   - Click the 🗑️ button in the sidebar to clear all history and statistics

## 📊 Statistics Tracked

- **Total Questions** - Number of questions asked
- **Success Rate** - Percentage of successful API responses
- **Average Response Time** - Average time taken for responses
- **Failed Requests** - Number of failed API calls

## 🛡️ Rate Limits

The app has built-in rate limiting (3 seconds between requests) to prevent hitting API quota limits.

**Gemini API Free Tier Limits:**
- 15 requests per minute
- 1,500 requests per day
- 1 million tokens per minute
